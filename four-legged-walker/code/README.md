# Code Readme

everything-combined.c is our working main code for our walker. It combines the I2C, interrupts, UART, servo motor, and stopwatch skills to create one working crawler. Within the code itself, we have all the various imports from these skills with their corresponding functions, as well as one big main function called "test-alpha-display" which performs the actual operations of the crawler. The function name is the same as from the i2c skill, because for some reason we were getting errors when we changed it.
