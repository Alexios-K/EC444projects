# EC444 Robotics and Autonomous Systems

Coursework and project archive for Team 1 in Boston University's EC444 course.
The projects explore embedded systems, sensor fusion, localization, computer
vision, and autonomous vehicle control using ESP32 hardware, Python, and
JavaScript.

## Projects

| Quest | Project | Focus |
| --- | --- | --- |
| [Four-legged walker](four-legged-walker/) | Controllable four-legged walker | Embedded control and robot locomotion |
| [Sensor fusion localization](sensor-fusion-localization/) | Sensor fusion localization | ESP32 sensors, filtering, and live visualization |
| [Human activity recognition](human-activity-recognition/) | From motion to meaning | Motion sensing and data interpretation |
| [Waypoint AI drive](waypoint-ai-drive/) | Waypoint AI drive | Imitation learning and autonomous Limo navigation |

## Repository notes

- Source code and project-specific setup instructions live in each quest's
  `code/` directory.
- Large recordings and sensor datasets are included where they are needed to
	reproduce the coursework. Some hardware-dependent projects require the
	original ESP32, Limo, or sensor setup.
- Build output, local dependency folders, editor files, and machine-specific
	configuration are excluded through `.gitignore`.
